https://svelte.dev # Basic ## 组件 可复用的包含 HTML, CSS, JS 代码块，文件名以 `.svelte` 后缀。 ``` <script module> // module-level logic goes here // (you will rarely use this) </script> <script> // instance-level logic goes here </script> <!-- markup (zero or more items) goes here --> <style> /* styles go here */ </style> ``` script module - 只在初始化时执行一次，而不带 `module` 属性的 script 在每个组件实例中都会执行。 - 里面的变量在组件内其他地方都可以被引用，反之则不行。 - 一般直接写在 `$lib` 下 js module。 CSS scope 仅限于本组件。 导入组件 `import Nested from './Nested.svelte'`，使用 `<Nested />` （组件名首字母大写） 传递变量给组件，使用 `$props`。 传递 CSS 变量给组件 `<Nested --color="red" />`, 组件中定义变量 `background-color: var(--color, #ddd)` ``` <script> let name = 'Rick Astley'; let src = '/tutorial/image.gif'; let string = `this string contains some <strong>HTML!!!</strong>`; </script> <h1>Hello {name.toUpperCase()}!</h1> <img {src} alt="{name} dances." /> <p>This is a string contains html: {@html string}</p> <style> p { color: goldenrod; font-family: 'Comic Sans MS', cursive; font-size: 2em; } </style> ``` ### Lifecycle 客户端导航（非浏览器直接修改）：不会重建组件(没有 onMount 事件，需使用 afterNavigate)。 - 点击链接：`<a href="/?t=2">改变参数</a>` (或者改变 path，但 layout 没变，则 page 重建，layout 不重建) - 代码跳转：`import { goto } from '$app/navigation'; goto('/?t=2');` - 浏览器前进 / 后退按钮 当页面刷新，手动地址栏改变参数或 path，页面会重新加载及 onMount。(snapshot / sessionStorage 只有 tab 关闭才会清除，刷新不会) 注意浏览器的 Back-Forward Cache（仅发生在前进后退），所有都会保存和恢复。 所以， - 全局状态：全局 `$state()` module。 - 页面状态：snapshot。 - 临时状态（刷新重置）：local 普通变量。 组件生命周期事件顺序(child 是 page 里的组件)： 1. layout loaded 1. page loaded 1. child loaded 1. child mounted 1. page mounted 1. layout mounted 1. child after navigate 1. page after navigate 1. layout after navigate 注意这只是事件触发顺序，它们不会互相 block 调用（当其中有 await 调用 yeild 出去的时候）。 ## Reactivity/Rune ### $state 让一个变量具有 reactivity，要使用 `$state(...)` rune。当其改变（包括重新赋值和直接修改）时，HTML 中的引用才会随之变化。一旦被标记，即使重新赋值新对象(如 `a = {}`)，仍具有 reactivity。 Deep reactivity: 可以作用于数组或对象，`$state([...])`, `$state({...})`，但单独解构取出的成员不具有 reactivity。这种作用是递归的，直到遇到非简单对象(如由 class or Object.create 创建的对象)。不能作用于 class 实例，可以作用于 class 成员(用 state 初始化)。`svelte/reactivity` 有一些 built-in 的 reactivity class。 `$state.raw` 作用的对象不能修改（无效果），主要是为了提高性能。 `$state.snapshot` dump 一个原始对象，可以传递到其他无需 reactivity 的地方。 比如 state 不能直接输出，要使用 snapshot: `console.log($state.snapshot(numbers))`。直接使用 inpsect 当 state 变化时打印日志: `$inspect(numbers).with(console.trace)` `$state.eager` 直接响应变化，而不用等 await。 rune 可以在非组件的普通 JS 中使用 `export const counter = $state({ count: 0 })` (直接具有 reactivity, 不需要用 `svelte/store`)，但文件名必须以 `.svelte.js` 结尾。可以直接导出，但不要对其重新赋值。 ### $derived 必须有一个变量接收，如果有依赖（读取）state 变化(not deep)，则触发： ``` let count = $state(0); let doubled = $derived(count * 2); let total = $derived(await a + b); ``` await 后面变量的也会被track（仅限表达式自己的变量）。 直接update derived变量也会触发更新，而不用等依赖变化。 不同于 `$state`，`$derived` 返回的是就是结果变量本身。 ``` let { a, b, c } = $derived(stuff()); // 相当于 let _stuff = $derived(stuff()); let a = $derived(_stuff.a); let b = $derived(_stuff.b); let c = $derived(_stuff.c); ``` `$derived.by` 接受一个函数，可以实现复杂逻辑。`$derived(expression)` 相当于 `$derived.by(() => expression)` ### $effect `$effect` rune 根据用到的 state 的变化触发（同步读取，await 后面无效）。如果 state 被有条件使用，那必须条件为真时才会触发。 Not deep: 只 track state 对象本身的变化，而不是对象成员属性的变化。（在 dev 时，可以用 `$inspect`） DOM 的变化可以看作是内部的 effect。在 effect 里面不应该去更新 state。 返回一个清理函数，在每次 effect 重新调用之前或组件销毁时被调用。 ``` $effect(() => { const id = setInterval(() => { elapsed += 1; }, interval); return () => { clearInterval(id); }; }); ``` `$effect.pre` 在 DOM 更新之前运行。 `$effect.tracking` 表示是否在 tracking 环境，如 effect 内部。 `$effect.pending` 表示在当前 boundary 下有多少 promises 在等待状态。 `$effect.root` 创建一个不会自动清理的 effect（独立于组件）。 经典用法： ``` <script> import { tick } from 'svelte'; let div = $state(); let messages = $state([]); $effect.pre(() => { if (!div) return; // not yet mounted // 监控消息长度：reference `messages` array length so that this code re-runs whenever it changes messages.length; // 读取当前（旧 DOM）的滚动位置，判断用户是否已经贴近底部 if (div.offsetHeight + div.scrollTop > div.scrollHeight - 20) { // 等待 Svelte 将新消息渲染到 DOM 中 tick().then(() => { // DOM 已经包含了新消息（scrollHeight 已经变成了最新的高度），再精准滚动到最新的底部 div.scrollTo(0, div.scrollHeight); }); } }); </script> <div bind:this={div}> {#each messages as message} <p>{message}</p> {/each} </div> ``` ### $props `$props` 接收从组件使用者传入的变量，可以有默认值：`let { answer = 'default value' } = $props()`，使用 `<Nested answer={42} />` 当父组件值变化，子组件对应值也会变化。子组件可以对变量重新赋值（不会同步到父组件，除非使用 `$bindable`），但不要修改其属性。 ### $bindable 可以让子组件的值变化通过 $props 同步到父组件。 ### $inspect `$inspect` 当 state 变化时(deep)，使用 `console.log` 输出。 `$inspect(...).with` 可以使用自定义函数替换 `console.log` 输出。 `$inspect.trace`: 用在 effect 或 derived 里面，可以打印出谁触发了这个 effect/derived。 ``` $effect(() => { $inspect.trace("effect A"); state.value; }); ``` ### $host 用于 "custom element" 发送自定义事件。 ## 模版 HTML 中可以用大括号引用 JS 中的变量或表达式，不需要加引号（会自动 string coercion）。 布尔属性是否设置，看值是否为 truthy，其他属性是否设置看值是否为 nullish (null/undefined)。 如果属性名和变量名一样，如`src={src}`，可以简写为`{src}`。 `{@render ...}` 用来渲染 `#snippet` `{@html ...}` 嵌入 HTML 变量，不会转义。scoped style 不起作用，需要用 global。 `{@debug user}` 当变量变化时，打印到 console，并当 devtool 打开时，会暂停执行。可以是列表，不支持表达式。`{@debug}` 监控任意 state 变化。 `{let/const ...}` 定义本地变量。可以直接引用 `<script />` 里的变量。 ``` {#each boxes as box} {const area = box.width * box.height} {box.width} * {box.height} = {area} {/each} ``` `{@attach ...}` 相当于把一个 effect 加到一个元素上，在元素 mount 到 DOM 的时候（或者函数里依赖的 state 变化时）调用。 ``` <script> function myAttachment(element) { console.log(element.nodeName); // 'DIV' return () => { console.log('cleaning up'); }; } </script> <div {@attach myAttachment}>...</div> ``` ### Logic **if** ``` {#if count > 10} <p>{count} is greater than 10</p> {:else if count < 5} <p>{count} is less than 5</p> {:else} <p>{count} is between 0 and 10</p> {/if} ``` **each** ``` <div> {#each colors as color (color.id), i} <button style="background: {color}" aria-label={color} aria-current={selected === color} onclick={() => selected = color} >{i + 1}</button> {:else} <p>No colors!</p> {/each} </div> ``` 使用 key (color.id) 以避免迭代时增加或删除元素带来的问题。 无需具体元素，仅按次数迭代： ``` <div class="chess-board"> {#each { length: 8 }, rank} {#each { length: 8 }, file} <div class:black={(rank + file) % 2 === 1}></div> {/each} {/each} </div> ``` **key** 当 i 变化时，销毁并重新创建内容 ``` {#key i} <p in:typewriter={{ speed: 10 }}> {messages[i] || ''} </p> {/key} ``` **await** `let promise = $state(...)` ``` {#await promise} <p>...rolling</p> {:then number} <p>you rolled a {number}!</p> {:catch error} <p style="color: red">{error.message}</p> {/await} ``` **snippet** 定义可重用的代码块 ``` {#snippet figure(image)} <figure> <img src={image.src} alt={image.caption} width={image.width} height={image.height} /> <figcaption>{image.caption}</figcaption> </figure> {/snippet} ``` ### Events `onxxx` 监听 xxx 事件（大小写敏感），在 binding 事件之后触发 (bind:value -> oninput)。有的事件直接使用 `addEventListener`，有些则被委托。 使用 `import { on } from 'svelte/events'` (它使用委托，而避免直接使用 `addEventListener`)，可以让事件依赖声明顺序，`stopPropagation` 也能正确地被处理。 默认在冒泡阶段触发，如要在捕获阶段触发需在事件名后加上`capture` ``` <div onpointermove={onpointermove}> The pointer is at {Math.round(m.x)} x {Math.round(m.y)} </div> <div onpointermove={(event) => { m.x = event.clientX; m.y = event.clientY; }} >The pointer is at {m.x} x {m.y}</div> <div onkeydowncapture={(e) => alert(`<div> ${e.key}`)} role="presentation"> <input onkeydowncapture={(e) => alert(`<input> ${e.key}`)} /> </div> ``` ### Bindings `bind:` value 的变化也同步到变量。同名可以省略`={...}`。 ``` <input bind:value={value}> <input bind:value> <input type="checkbox" bind:checked={yes}> <input type="radio" name="scoops" value={number} bind:group={scoops} /> <input type="checkbox" name="flavours" value={flavour} bind:group={flavours} /> <select bind:value={selected} onchange={() => answer = ''}> <select multiple bind:value={flavours}> {#each ['cookies and cream', 'mint choc chip', 'raspberry ripple'] as flavour} <option>{flavour}</option> {/each} </select> <textarea bind:value={value}></textarea> <details bind:open={isOpen}></details> <div contenteditable="true" bind:innerHTML={html}></div> ``` 用 get / set 函数，可以做检查和转换。 ``` <input bind:value={ () => value, (v) => value = v.toLowerCase()} /> ``` `<audio> / <video> / <img>` 也有一些可以双向绑定或 readyonly 的属性。所有可视元素都有一些关于尺寸的 readyonly 属性可以绑定。 `bind:this` 可以绑定 DOM 元素，但在 mount 之前值是 undefined（可以放到 effect 里操作）。 ``` <canvas bind:this={canvas}></canvas> ``` 绑定组件时可以调用导出的方法。 ``` <ShoppingCart bind:this={cart} /> <button onclick={() => cart.empty()}> Empty shopping cart </button> ``` 可以绑定组件的属性 `<Keypad bind:bindableProperty={pin} />`，但必须用 `$bindable` 声明。 ``` <script> let { readonlyProperty, bindableProperty = $bindable() } = $props(); </script> ``` ### Styles `style:` 设置 style，可以有多个。相同属性合并的时候，前面的优先。 ``` <!-- These two are equivalent --> <div style:color="red">...</div> <div style="color: red;">...</div> <div style:color>...</div> <div style:color|important="red">...</div> <div style:--columns={columns}>...</div> ``` 使用数组或对象作为 class 属性值，可以使用变量名作为 class 名字。当其为真时，自动加上 class。 ``` <button class="card {flipped ? 'flipped' : ''}" onclick={() => flipped = !flipped}> <button class={["card", { flipped }]} onclick={() => flipped = !flipped}> <button class={{"card": true, flipped }} onclick={() => flipped = !flipped}> <button class="card" style="transform: {flipped ? 'rotateY(0)' : ''}; --bg-1: palegoldenrod; --bg-2: black; --bg-3: goldenrod" onclick={() => flipped = !flipped}> <button class="card" style:transform={flipped ? 'rotateY(0)' : ''} style:--bg-1="palegoldenrod" style:--bg-2="black" style:--bg-3="goldenrod" onclick={() => flipped = !flipped}> ``` ### Actions `use:` (deprecated, use `@attach`) action 是一个函数，里面实现有一个 effect。 ``` function tooltip(node, fn) { $effect(() => { const tooltip = tippy(node, fn()); return tooltip.destroy; }); } ``` 当这个 node mount 到 DOM 的时候调用，unmount 的时候调用清理函数。 ``` <button use:tooltip={() => ({ content })}> Hover me </button> ``` ### Transition `transition:` `in:` `out:` `animate:` 默认 transition 只作用于直接的元素创建和销毁时，加上 `global` 使包含其的元素创建和销毁时也能触发。 ``` <p transition:fade> Fades in and out </p> <p in:fly={{ y: 200, duration: 2000 }} out:fade> Flies in, fades out </p> <p transition:fly={{ y: 200, duration: 2000 }} onintrostart={() => status = 'intro started'} onoutrostart={() => status = 'outro started'} onintroend={() => status = 'intro ended'} onoutroend={() => status = 'outro ended'} > Flies in and out </p> <div transition:slide|global> {item} </div> ``` animate 当一个元素增加或删除时，它并不执行。它只作用于 keyed each 的直接子元素上，当子元素变化时执行。 ``` <!-- When `list` is reordered the animation will run --> {#each list as item, index (item)} <li animate:flip>{item}</li> {/each} ``` ### await 若要在下面地方使用 await，需要设置配置参数 `experimental.async`： - `<script>` 顶层 - `$derived(...)` 声明内 - 模版内 ## Library svelte onMount: 当一个组件 mount 到 DOM 的时候调用，就像 `$effect`，不过只调用一次。可用于组件初始化。可以返回一个函数以在 unmount 的时候被调用。SSR 的时候不会执行。 svelte onDestroy: 在组件 unmount 的时候调用，唯一一个只运行在 SSR 的。 svelte tick: 返回一个 promise，在任何等待的状态被应用到 DOM 后，resolve。 svelte settled: 类似 tick，但要等更新导致的所有后续异步操作完成。 # SvelteKit ## Routing 基本页面(page): `src/routes/+page.svelte` -> `/` `src/routes/about/+page.svelte` -> `/about` `src/routes/blog/[slug]/+page.svelte` -> `/blog/{name}` 共享页面(layout): 作用于基本相邻页面和基本/共享子页面(children)，可以嵌套。 `src/routes/+layout.svelte` ``` <script> let { children } = $props(); </script> <nav> <a href="/">home</a> <a href="/about">about</a> </nav> {@render children()} ``` ## Data 执行在 server 端，需要导出`load()`函数 `src/routes/blog/+page.server.js` ``` import { posts } from './data.js'; export function load() { return { summaries: posts.map((post) => ({ slug: post.slug, title: post.title })) }; } ``` page 使用： ``` <script> let { data } = $props(); </script> <h1>blog</h1> <ul> {#each data.summaries as { slug, title }} <li><a href="/blog/{slug}">{title}</a></li> {/each} </ul> ``` 共享数据源：基本或共享（相邻或子）页面可以引用共享数据源，但共享页面引用不到（相邻）普通数据源的数据。 `src/routes/blog/+layout.server.js` page 使用： ``` <script> let { data, children } = $props();
